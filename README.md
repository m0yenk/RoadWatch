# RoadWatch – Road Damage Reporting System

## About the Project
RoadWatch is a web-based road damage reporting system designed to help users report road problems such as potholes, damaged roads and cracks.

The project provides a simple interface to submit reports, view reported issues and manage their demo status.

## Problem Statement
Damaged roads can cause accidents, vehicle damage and traffic problems. Reporting these issues through traditional methods can be difficult and time-consuming.

RoadWatch demonstrates a simple digital platform for reporting and tracking road damage.

## Features
- Submit road damage reports
- Select damage type and severity
- Add location and description
- Upload a damage photograph
- Generate a unique report ID
- View submitted reports
- Search and filter reports
- Change report status
- Responsive interface for mobile and desktop

## Technologies Used
- HTML – Website structure
- CSS – Design and responsive layout
- JavaScript – Form handling and website functionality
- Local Storage – Saving demo reports in the browser

## How to Run Locally
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

## Project Limitations
This is a frontend demonstration project. Reports are stored in the browser's local storage and are not shared between different devices or users. It does not currently have a backend database, real user authentication or municipal authority integration.
